# Fyne-on - GitHub Crawler с Markov Chains

Высокопроизводительный краулер GitHub, использующий цепи Маркова для интеллектуального обхода и Badger KV для эффективного хранения данных.

## 🚀 Возможности

- **Обход на основе цепей Маркова**: Интеллектуальный обход с использованием цепей Маркова
- **Хранилище ключ-значение**: Badger DB для быстрого и надежного хранения
- **REST API**: Полнофункциональный REST API для запроса и управления данными
- **Дедупликация**: Дедупликация на основе хешей SHA256
- **Масштабируемость**: Архитектура масштабируется до 10,000+ репозиториев и контактов

## 📂 Архитектура

### Основные компоненты

1. **BadgerDB** (`pkg/database/badgerdb.go`)
   - Обертка над Badger для операций ключ-значение
   - Хеширование SHA256 для дедупликации

2. **GitHub Crawler** (`internal/core/crawler/github.go`)
   - Парсинг GitHub API и HTML
   - Сбор информации о репозиториях, issues и PR

3. **Storage Service** (`pkg/storage/storage.go`)
   - CRUD операции для всех типов данных
   - Дедупликация на основе хешей

4. **Markov Chain** (`internal/core/markov/markov.go`)
   - Интеллектуальный выбор URL для обхода

## ⚡ Быстрый старт

```bash
go build -o bin/app.exe ./cmd/app
./bin/app.exe
```

API доступен на `http://localhost:3000`

## 📊 Данные

### Типы собираемых данных

- **Repositories**: GitHub репозитории
- **Issues**: Проблемы и задачи
- **Pull Requests**: Запросы на добавление кода
- **Contacts**: Информация о пользователях

## 🔗 Основные endpoints

| Метод | Endpoint | Описание |
|-------|----------|---------|
| GET | /health | Проверка здоровья |
| GET | /stats | Статистика базы данных |
| POST | /crawler/start | Запуск краулера |
| POST | /export/all-jsonl | Экспорт в JSONL |

## 📝 Экспорт данных

Поддерживаются форматы:
- JSONL (JSON Lines) - рекомендуется для LLM
- Parquet - для аналитики больших данных
